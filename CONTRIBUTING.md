# Contributing to Nubo Native Platform (NNP)

This repository — **PICC - PP - NNP DMS Management** — is part of the **Platform Infrastructure and Core Components (PICC)** area of the Nubo Native Platform. Contributions are welcome under the **Apache 2.0 License**.

## Before you start
Contribute against an open **Issue**, the published **Roadmap**, or a proposed **enhancement**. Email **contribution@nubons.com** with your approach and category first; we respond within 5 working days.

## Steps
1. Fork & clone the repository.
2. Make a focused change on a feature branch (`feature/*`, `bugfix/*`).
3. Ensure code formatting matches Google Java Style and passes tests (`./mvnw clean test spotbugs:check`).
4. Note your testing verification steps in the PR description.
5. Open a Pull Request with a clear summary of modifications.

## Security
**Never commit secrets, tokens, `.env` files, or private credentials.** See [SECURITY.md](SECURITY.md). All participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
